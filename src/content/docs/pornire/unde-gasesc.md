Meniu tipic (modulele pot lipsi pe firma ta dacă nu sunt licențiate / activate).

## Vânzări

| Ai nevoie de… | Mergi la… |
|---------------|-----------|
| Ofertă / comandă | **Vânzări → Comenzi** |
| Coș din magazin (operator) | **Vânzări → Kiosk** |
| Facturi | **Vânzări → Facturi** |
| Contracte mentenanță | **Vânzări → Contracte** (dacă e activ) |
| Clienți / parteneri | **Vânzări → Clienți** |
| Livrări | **Vânzări → Livrări** |
| Rapoarte | **Vânzări → Rapoarte** |

## Depozit

| Ai nevoie de… | Mergi la… |
|---------------|-----------|
| Picking | Detaliul comenzii în stare **Picking** (nu există meniu separat) |
| Transferuri între firme / gestiuni | **Depozit → Transferuri comenzi** |
| Gestiuni, NIR, inventar (nativ) | **Depozit → …** (documentele de gestiune) |

## Catalog

**Catalog → Produse** (inclusiv produse compuse + rețetă), categorii, sincronizare canale.

## Producție

**Producție → Ordine de producție** / panou — când modulul e activ pe firmă.

## Pontaj

Intrare / ieșire, vizite, ore pe lucrare, pontaj lună — din meniul **Pontaj** (și/sau PWA).

## Administrare

| Cine | Unde |
|------|------|
| Admin firmă | Setări firmă, utilizatori, serii, taxe/UM — fără credențiale SmartBill/GLS de vendor |
| Vendor (Tech admin) | Firme, integrări / canale, setări procesare, cron, loguri, status integrări |

## Notificări

**Clopotul** din meniul principal: alerte când un serviciu (ex. SmartBill / GLS) e căzut sau apar evenimente de urmărire.

## Următorul pas

Alege [rolul tău](/pe-rol/vanzari/) sau vezi [fluxul comenzii](/fluxuri/comanda-la-expediere/).
