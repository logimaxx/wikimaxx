| Obiecție | Direcție de răspuns |
|----------|---------------------|
| „Avem deja SmartBill / Woo” | Exact — MaxxOps **nu le înlocuiește**; le leagă pe un flux operațional. |
| „E încă un soft de învățat” | Înlocuiește tab-urile + Excel-ul dintre sisteme; un ecran pentru starea comenzii. |
| „Nu vrem să schimbăm curierul / contabilitatea” | Model pe **adaptoare**; SmartBill/GLS/Woo/eMAG sunt exemple, nu lacăt. |
| „Producția noastră e prea complexă” | Ofertarea pe compuse e matură; atelierul e ordine de lucru legate de comandă — **nu** MES. Califică dacă ajunge. |
| „Facem doar retail simplu” | Arc retail: canale → picking → factură → AWB; multi-firmă dacă e cazul. |
| „Avem tehnicieni pe teren” | Preset teren: lucrare la client înainte de factură, pontaj, contracte. |
| „Cât costă / cât durează” | Completează aici cu pachetul comercial intern (nu pe site-ul public). |
| „Ne trebuie e-Factura / plăți card” | Limite oneste: nu e în scope-ul curent ca depunere / procesator. |

Actualizează tabelul după fiecare demo în care auzi o obiecție nouă.
