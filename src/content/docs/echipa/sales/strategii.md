Schelet — completează cu CRM-ul / tool-urile voastre reale.

## Etape

```
Lead → Calificare → Demo → Propunere → Kickoff → Go-live → Adoptie
```

| Etapă | Scop | Artefact |
|-------|------|----------|
| Calificare | ICP, arc (producție / retail / teren) | Note + [Pentru cine](/echipa/sales/pentru-cine/) |
| Demo | Un flux pe ecran, pe durerea lor | Agenda demo (mai jos) |
| Propunere | Scope, module, efort, preț | Ofertă comercială (template intern) |
| Kickoff | Acces, firme, integrări, training | Checklist implementare |
| Go-live | Credențiale verificate, scenarii MVP | Semnale din ghidurile utilizator |
| Adopție | Academy + video; campion client | Link [academy.maxxops.ro](https://academy.maxxops.ro) (zona publică) |

## Agenda demo (30–45 min)

1. Confirmare durere (5 min)
2. Pitch scurt — [Produsul](/echipa/sales/produsul/) (3 min)
3. Demo pe **un** flux (15–20 min) — nu turul tuturor meniurilor
4. Limite oneste + întrebări (5–10 min)
5. Next step clar (propunere / trial / kickoff)
