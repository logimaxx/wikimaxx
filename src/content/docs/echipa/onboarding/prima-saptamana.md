Checklist orientativ — ajustează pe rol (sales / implementare / support).

## Ziua 1–2 — Context

- [ ] [Bun venit](/echipa/onboarding/bun-venit/) + contacte
- [ ] [Ce este MaxxOps](/pornire/ce-este-maxxops/) + [Unde găsesc ce](/pornire/unde-gasesc/)
- [ ] Site produs: [maxxops.ro](https://maxxops.ro) (poziționare publică)
- [ ] [Produsul pe scurt](/echipa/sales/produsul/) (chiar dacă nu ești sales — același limbaj)

## Ziua 3–4 — Produs pe ecran

- [ ] Login pe instanța de demo / staging
- [ ] Parcurge un flux: ofertă → confirmare → (picking) — vezi [Comandă → expediere](/fluxuri/comanda-la-expediere/)
- [ ] Un ghid pe rol: [Vânzări](/pe-rol/vanzari/) sau [Depozit](/pe-rol/depozit/)
- [ ] Integrări pe scurt: [SmartBill](/integrari/smartbill/), [GLS](/integrari/gls/), [canale](/integrari/canale/)

## Ziua 5 — Rolul tău

| Rol | Focus |
|-----|--------|
| Sales | [Pentru cine](/echipa/sales/pentru-cine/), [Obiecții](/echipa/sales/obiectii/), [Strategii](/echipa/sales/strategii/); 1 demo umbră |
| Implementare / CS | Fluxuri + pe-rol; unde se blochează comenzile |
| Colaborator | [Colaboratori externi](/echipa/onboarding/colaboratori/); scope + canale de comunicare |

## După o săptămână

Ar trebui să poți explica în 2 minute: **ce e MaxxOps, pentru cine, ce nu e**, și să arăți pe ecran o comandă din captare spre finalizare.
