După publicare, lipește URL-ul YouTube în tabel și, opțional, un embed pe pagina de flux corespunzătoare:

```html
<iframe
  width="560"
  height="315"
  src="https://www.youtube.com/embed/VIDEO_ID"
  title="MaxxOps — …"
  allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
  allowfullscreen
></iframe>
```

(În MDX poți folosi același iframe; în Markdown simplu, un link e suficient la început.)
